# Lumis-Userbot

> **Ваш уникальный юзербот telegram который поможет вам быстро и удобно парсить участников и сообщения.**

## Функционал

- 📊 **Парсинг участников чатов**
- 📰 **Парсинг сообщений**
- 💾 **Сохранение результатов в JSON**

## Установка

### Клонируйте репозиторий и откройте его:
```bash
  $ git clone https://github.com/Dev-Baron/lumis-parsing-userbot.git
  $ cd lumis-parsing-userbot
```

### Установите зависимости:
```bash
$ pip3 install requirements.txt
```

### Создайте файл .env и добавьте:
```env
  API_ID=ваш_API_ID
  API_HASH=ваш_API_HASH
```

### Запустите:
```bash
  $ python3 main.py
```
